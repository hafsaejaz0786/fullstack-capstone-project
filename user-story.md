# GiftLink User Stories

## User Story 1: Browse Available Items
- **As a** Registered / Guest User
- **I want to** view a list of all donated household gifts
- **So that** I can find items I need without buying new ones.

## User Story 2: Search and Filter Items
- **As a** Registered User
- **I want to** search gifts by name and filter by category
- **So that** I can quickly locate relevant items near me.

## User Story 3: View Detailed Item Information
- **As a** Registered User
- **I want to** view full item specifications, donor info, and location
- **So that** I can decide whether to request the item.

## User Story 4: User Authentication (Register & Login)
- **As a** New User
- **I want to** create an account and log in securely using JSON Web Tokens (JWT)
- **So that** my personal preferences and profile details are protected.
